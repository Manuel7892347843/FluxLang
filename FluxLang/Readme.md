# FluxLang Documentation
Flux is a C-style language that compiles to Assembly ([NASM](https://nasm.us/)) and uses [Clang](https://llvm.org/) as a linker, created by LLVM, and
it's an imperative language.
---
In order to use it it's necessary to:
1) Have NASM installed and in your **PATH**
2) Have Clang installed and in your **PATH**

To understand how to use the language and how it works, check the documentation below:
