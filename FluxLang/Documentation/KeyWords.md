# Keywords (FluxLang)
In Flux, the keywords currently available are:  
- Types:
  - void
  - int
  - char
  - ptr
- Custom Types: 
  - struct
- Selection Statements:
  - if
  - else
- Cycle Statements:
  - for
  - while
  - do
- Memory Management:
  - memory_allocation
  - free_memory
  
- Input/Output:
  - input
  - input_str 
  - print 
  - print_memory
- Libraries:
  - import
- Functions:
  - return
- Time:
  - time
  - sleep
  - rand
  - srand
- Math: 
  - sqrt (uses C function)
- Exit Statements:
  - exit
