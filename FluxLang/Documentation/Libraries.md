# Libraries (FluxLang)

In Flux, to expand the capabilities of the language. FluxLang has nine standard libraries.  
To use a library, it must be imported with the `import` keyword.
```Flux
import "algo.flx";

void main(){
    
}
```
1) [`algo.flx`](../lib/algo.flx): A library made with a set of algorithms.
2) [`array.flx`](../lib/array.flx): A library made with a set of array functions.
3) [`ctype.flx`](../lib/ctype.flx): A library made with a set of character type functions.
4) [`io.flx`](../lib/io.flx): A library made with a set of I/O functions.
5) [`math.flx`](../lib/math.flx): A library made with a set of mathematical functions.
6) [`mem.flx`](../lib/mem.flx): A library made with a set of memory functions.
7) [`random.flx`](../lib/random.flx): A library made with a set of functions to work with random numbers.
8) [`std.flx`](../lib/std.flx): A library made with a set of standard functions.
9) [`string.flx`](../lib/string.flx): A library made with a set of string functions.
